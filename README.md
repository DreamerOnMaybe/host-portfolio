# Влад Тётёркин — Портфолио ведущего мероприятий

> Современный, высокопроизводительный одностраничный промо-сайт (Landing Page) для харизматичного ведущего мероприятий из Омска.

🔗 **Демо:** [vlad-teterkin.netlify.app](https://vlad-teterkin.netlify.app)

---

## 📌 О проекте

Сайт разработан с акцентом на мобильный UX, чистый визуал и максимальную скорость загрузки. Вместо тяжелых многостраничных структур реализован лаконичный single-page формат, позволяющий потенциальному заказчику быстро ознакомиться со стилем работы ведущего, посмотреть живые кадры с событий и выйти на связь в один клик.

### Основной функционал:
- **Интерактивные фотогалереи:** модальные окна для просмотра репортажных фотографий с мероприятий (с клавиатурной навигацией, счетчиком кадров и поддержкой доступности).
- **Слайдер отзывов:** легковесный текстовый слайдер с плавной сменой цитат, циклическим переключением стрелками и автогенерацией буллетов.
- **Мобильная оптимизация:** отсутствие залипающих `:hover` эффектов на тач-экранах, защита от случайных срывов скролла, адаптивная верстка под любые разрешения.
- **Производительность и доступность:** использование современных форматов графики (`.webp`), ленивая загрузка (`loading="lazy"`), проработанные ARIA-атрибуты и управление фокусом (`blur`/`inert`).

## 🛠 Стек технологий

- **HTML5:** семантическая разметка, доступность (a11y).
- **SCSS / CSS3:** методология БЭМ (BEM), CSS Grid, Flexbox, флюидная типографика и отступы через `clamp()`, медиа-запросы `@media (hover: hover)`.
- **Vanilla JavaScript (ES6+):** модульная структура без тяжелых сторонних библиотек и фреймворков.
- **Vite:** быстрая сборка и локальный сервер разработки.
- **Netlify:** автоматический CI/CD деплой при пуше в ветку `main`.
